# Helper 助手

一个为**教师、公务员及体制内员工**量身打造的实用工具箱，帮助日常工作更高效、更规范。

## 适用人群

- 教师：课件、教案、公文材料的格式处理与资料整理
- 公务员 / 体制内员工：公文写作、材料汇总、格式规范等高频事务

## 主要功能

- **格式转换**：支持常见办公文档（Word、PDF、Excel、PPT、Markdown 等）之间的相互转换，确保材料符合体制内行文规范。
- **资料查询**：内置资料检索能力，方便快速查找政策、模板、规范文件等参考资料。
- **更多辅助工具**：持续补充中，目标是覆盖体制内日常办公的常见痛点。
